# 兼容性与验收

支持对象是实现 `SKILL.md` 目录格式的 AI 宿主，而不是裸模型权重。模型能理解文本，并不代表产品允许安装技能。

## 无账号依赖

不包含作者账号、凭证、API Key 或硬编码绝对路径。诊断指令与基础脚本可离线运行；可选 H3 适配器仅在使用者配置自己的 API 并要求出片时联网。Python 脚本仅使用标准库；宿主提供模型推理、文件权限与可选执行能力。

## 输出随能力适配

- 无工具：完整诊断＋步骤表／Mermaid 源码；没有真正创建文件。
- 有文件工具无 Python：增加 Markdown 和 JSON；明确未执行校验。
- 有 Python 3.9+：校验、测算、HTML、SVG、分镜。
- 无真实业务参数：交付待采集项与条件方案，不植入样例工时。

CLI 安装可选使用 Skills 项目，支持目标列表由该工具维护。用 `npx skills --help` 确认本机版本与选项；不把安装工具支持的宿主数量当作本技能已在所有宿主实测的数量。

## 维护者检查

```bash
python3 scripts/verify_distribution.py
```

该检查将 ZIP 解包到独立临时目录，从解包后的路径执行首次演示，核对资源和结果、非空目录保护、无参数模型和无效模型。它验证可移植包与脚本，不验证所有模型的推理效果。

发布时还应记录实际进行的安装工具检查与无工具任务试用。未登录、未安装或未持有的其他 AI 产品，不能宣称端到端实测通过。普通聊天工具的提示词备用版不等于原生安装。
